# 收藏加载、超时与重试

## 背景

iPhone 的 PWA / Safari 曾出现头像已显示、收藏区域却完全空白的情况。登录验证与收藏加载独立进行；原先页面一直等待 IndexedDB，数据库请求没有返回时，卡片和空状态都不会渲染。云端下载后也要等本地写入才能显示。

## 当前行为

- 首屏直接显示“正在加载收藏…”，本地读取成功后隐藏。
- 云端检查和下载在后台静默进行，不显示“正在检查云端收藏…”之类的提示：卡片已经渲染出来，提示条一出一收会把页面顶得跳动。只有超时或失败才显示错误和“重试”；点“重试”时提示条已经在，原地换成加载中（`showNavLoadStatus()` 的 `quiet` 选项）。下载进度仍看页眉进度条。
- IndexedDB 打开连接和每个事务分别限时 5 秒，失败后重新连接、重试一次。并发调用共享打开请求；迟到的连接会关闭，超时事务会中止。
- 写入以事务 `complete` 为成功标准，不能把请求 `success` 当作已经提交；处理 `blocked`、`abort`、`error`、连接关闭和版本变化。
- IndexedDB 不可用时读取 localStorage 备份；没有备份则明确报错，不把读取失败当成新用户，也不上传空数据。
- 写入降级使用 JSON，并设置 `navSiteStorageFallback:<数据键>`。后续优先读取这份最新副本，避免读到 IndexedDB 旧数据；数据库写入恢复后清除标记。标记和值必须一同保留。
- 登录验证、云端状态检查、收藏下载分别限时 15 秒，包含响应体读取；网络错误、超时或 5xx 自动重试一次，两次之间等待 1 秒。401 等鉴权错误不自动重试。收藏解压处理限时 15 秒。
- 下载成功后先渲染，再写本地缓存。缓存仍失败时显示“收藏已加载，但本机保存失败，请重试。”；不推进本地版本号。
- 自动重试仍失败时保留错误提示与“重试”按钮。手动重试不受同步检查的 10 秒节流影响。
- 本地读取失败或本地缺少收藏副本时，即使版本号相同也尝试云端恢复。有未同步的本机改动时先恢复本地读取，不上传空内存或下载覆盖。
- 新设备首次显示的默认示例数据不因补全置顶属性而自动上传，避免在恢复云端收藏之前覆盖云端。
- 自动下载期间切换账号、产生本机修改或待上传标记时，不应用旧响应；重复触发云端检查 / 下载时合并请求。

## 使用与验证

用户直接打开页面即可看到状态，失败后点击“重试”。重试不删除数据库或备份。

```bash
npm run test:frontend  # Node 标准测试运行器，模拟数据库及网络故障
npm test -- --run      # 现有 Workers 测试
npm run build
git diff --check
```

`test/frontend-loading.node.cjs` 覆盖打开和事务无回调、迟到连接、事务中止、降级存储、加载失败后重试、响应体超时、鉴权错误、相同版本恢复、缓存失败与并发响应保护。

人工验证时在 iPhone PWA / Safari 打开页面，观察加载提示；断网再重试应显示失败与按钮，恢复网络后重试应显示收藏。桌面浏览器和模拟请求不能替代实际 iPhone 验证。

## 注意事项

超时是每个阶段的上限，自动重试后的总等待时间会更长。后台页面计时器可能被系统暂停，回到前台后继续处理。读取失败提示保留到用户重试或云端恢复成功，不通过清空存储来恢复。

## 退出登录与本地数据清除

收藏和访问记录主要存于 IndexedDB，localStorage 另有备份、同步标记和便签草稿。只删除登录令牌不会删除这些内容。

点击用户菜单的“退出登录”先显示确认弹窗，文案为“是否同时清除保存在本地的数据？”。“同时清除本地数据”默认勾选，每次重新打开弹窗都会恢复勾选；取消、关闭或按 Esc 均保留登录状态。取消勾选时确认退出只结束登录；勾选时还会清除当前浏览器中本站的数据：

- `NavSiteDB/settings` 中的收藏、分类和访问统计。
- localStorage 中的收藏备份、访问记录、访问最多的固定位置、同步版本及待上传标记、`navSiteStorageFallback:*` 和 `noteDraft:*`。
- 当前标签页 sessionStorage 中的私密收藏解锁状态。

主题、强调色、侧边栏模式、分区顺序和工具偏好保留。清除完成后刷新页面，丢弃内存和页面里原有的收藏；刷新后会显示项目默认的示例收藏。云端数据、云端历史版本和浏览器扩展的存储不在清除范围内，未同步的本地内容会丢失。

退出先停掉同步与待执行的自动上传，立即移除本机登录令牌。清除期间暂停 IndexedDB 写入及 localStorage 备份，避免在途保存重建数据；迟到的云端上传响应不再写回版本号。数据库清除沿用事务超时与一次重试，只有事务提交成功才视为完成；失败时仍结束登录，并明确提示用户在浏览器设置中清除此站点数据。登录过期触发的自动退出继续保留本地数据，不弹出这个确认框。

`npm run test:frontend` 覆盖取消、保留数据退出、自动退出、清除全部副本、清除失败、清除期间在途保存和退出后的迟到响应。人工验证应使用可丢弃的本地测试数据，分别测试取消、不勾选退出、勾选退出；检查刷新后 IndexedDB 和上述 localStorage 键已清空，主题仍保留。
