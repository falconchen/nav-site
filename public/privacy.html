隐私政策

我们重视您的隐私保护

皮皮2047（以下简称「我们」或「本应用」）重视您的隐私。本政策说明您在使用本应用网站、浏览器扩展「皮皮2047 收藏助手」和 REST API 时，我们会处理哪些信息、存在哪里、怎么使用。

一、不登录时

不登录也能使用全部基础功能，您的收藏数据只保存在当前浏览器里（localStorage），不会上传到我们的服务器。清除浏览器数据会一并删除它们，建议定期导出备份。

二、我们收集的信息

  • 账户信息：通过 GitHub 或 Google 登录时，我们会获取并保存您的邮箱、用户名、昵称、头像地址和第三方账号 ID，以及账户创建时间和最近登录时间。我们不会获取您的第三方账号密码。
  • 收藏数据：登录后，您的分类、网址、标题、描述、图标等数据会同步保存到云端，并保留最近 5 个历史版本（历史版本 30 天后自动过期）。
  • 登录会话：每次登录会记录一条会话，包含浏览器的 User-Agent、创建时间和最近使用时间，用于在「管理设备」中展示已登录的设备并支持远程注销。会话到期后自动删除。
  • 个人令牌：如果您生成了 API 个人令牌，我们只保存令牌的 SHA-256 摘要、名称、创建时间和最近使用时间，不保存令牌明文。
  • 上传的图标：您上传或 AI 识别得到的网站图标会压缩后存到图床，并生成一个公开地址。知道该地址的任何人都能访问这张图片。
  • IP 地址：为防止接口被滥用，上传图标和 AI 识别会按 IP 地址限制请求频率，相关计数 60 秒后自动删除。

三、只保存在您设备上的信息

  • 访问统计：「访问最多」用到的点击次数和访问时间只保存在本机浏览器（IndexedDB），不会上传，也不会跨设备同步。
  • 界面偏好：主题、配色、上次停留的 tab 等设置保存在 localStorage。

本应用不使用 Cookie，不投放广告，也没有接入任何第三方统计分析工具。

四、私密收藏

「私密收藏」只是在界面上把网站隐藏起来并遮住描述，并没有加密。这些网站和其它收藏一样，以明文形式保存在本地、云端、历史版本、导出文件中，也能通过 API 读取。请不要把私密收藏当作保存敏感信息的地方。

五、AI 识别与网页抓取

使用「AI 识别」或通过扩展、API 只提交网址来添加网站时：

  • 我们的服务器会访问该网址，读取网页标题、描述、正文片段和图标。
  • 网页内容、您的分类名称以及每个分类下部分已收录网站的标题和域名，会发给 Cloudflare Workers AI 用于推荐分类和生成描述。这些内容不会用于其它目的。
  • 如果目标网站拦截了我们的访问，该网址可能会转交给 Jina Reader 代为读取。
  • 使用浏览器扩展收藏时，扩展会把当前网页的标题、描述和部分正文一起提交，用于在网页无法抓取时补全信息。

请避免对需要登录才能访问、或网址中包含个人信息的页面使用 AI 识别。

六、浏览器扩展

  • 扩展只在您打开扩展弹窗或使用右键菜单收藏时，读取当前标签页的网址、标题和页面内容，不会在后台读取您的浏览记录。
  • 您的个人令牌和设置保存在扩展自己的存储空间中。
  • 扩展会把新标签页和浏览器首页设为皮皮2047 导航站，可以在浏览器设置中改回。

七、第三方服务

本应用依赖以下第三方服务，它们会按各自的隐私政策处理相应数据：

  • GitHub、Google：账号登录认证。
  • Cloudflare：网站托管、Workers AI、登录会话存储。
  • Upstash：收藏数据和历史版本的存储。
  • Jina AI：网页被拦截时代为读取网页内容。
  • 字体和图标 CDN：页面会从 Google Fonts 和 Font Awesome CDN 加载字体与图标，这些服务可以看到您的 IP 地址。

我们不会出售您的个人信息，也不会将其提供给上述服务以外的任何第三方，法律要求的情况除外。

八、您的权利

  • 导出：随时通过页脚的「导出数据」下载完整的收藏数据。
  • 注销会话与吊销令牌：可以在用户菜单的「管理设备」中注销任意设备，在「个人令牌」中吊销任意令牌。
  • 删除：如需删除账户及云端数据，请发邮件联系我们，我们会在核实身份后处理。

九、未成年人

我们不会有意收集未成年人的个人信息。如果您是未成年人，请在家长或监护人同意后使用本应用。

十、政策更新

本政策可能随功能变化而更新，更新后会修改本页的「最后更新日期」。重大变更会在网站上提示。

十一、联系我们

如对本政策有疑问，或希望行使上述权利，请联系：support@pipi2047.eu.org
