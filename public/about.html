About

皮皮2047

把常去的网站，收进一本随手可翻的网址簿。

关于皮皮2047

皮皮2047 是一个个人网址导航站：把常用网站分门别类放在一页里，打开就能找到。数据默认保存在浏览器本地，不登录也能完整使用；登录后可以在多台设备间同步。

核心功能

多视图浏览

最近添加、访问最多、特别关注、全部网站四个视图，手机上左右滑动切换

自定义分类

分类名称、图标、顺序都能自己改，367 个图标可选

自动填写

输入网址，自动补全标题、描述、图标，并参考你已有的收藏推荐分类

云端同步

改动后自动保存到云端，保留最近 5 个历史版本，可随时回退

浏览器扩展

「皮皮2047 收藏助手」支持 Chrome 和 Firefox，一键收藏当前网页

私密收藏

单独的私密 tab，默认锁定，描述打码，不出现在其它视图和搜索里

更多功能

  • 访问最多：按访问次数和最近访问时间综合排序，统计只保存在本机，不上传
  • 网址详情：鼠标悬停卡片可查看完整描述，一键复制网址或 Markdown 链接
  • 个性化外观：浅色 / 深色主题、多种配色、紧凑侧边栏
  • 导入导出：数据可随时导出为文件备份，也能从文件导入
  • REST API：生成个人令牌后，可以用脚本或第三方工具读写自己的收藏

登录方式

支持 GitHub 和 Google 账号登录。两个账号邮箱相同时会自动合并为同一个用户，数据共用。

技术实现

  • 前端：原生 JavaScript、HTML5、CSS3，没有使用框架
  • 后端：Cloudflare Workers + Hono
  • 存储：Upstash Redis 保存收藏数据和历史版本，Cloudflare KV 保存登录会话
  • AI：Cloudflare Workers AI（Llama 3.3 70B）
  • 源代码：github.com/falconchen/nav-site

隐私说明

  • 不投放广告，也不接入任何第三方统计分析
  • 私密收藏只是在界面上隐藏，云端和导出文件里并没有加密
  • 完整说明请参阅 隐私政策 和 使用条款
