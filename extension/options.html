新标签页与首页

显示上面填的导航站，地址栏保持为空，可以直接输入网址或搜索；关掉后恢复 Chrome 自带的新标签页。 首页固定为 ，这是 Chrome 的限制，只能写死在扩展里，改了导航站地址也不会跟着变。 要在工具栏显示主页按钮，请到 Chrome 外观设置 打开「显示主页按钮」。 新标签页底部那条显示扩展名和「自定义 Chrome」的页脚是 Chrome 自带的，扩展关不掉： 在页脚上右键选「在新标签页上隐藏页脚」即可。

新标签页显示上面填的导航站，地址栏保持为空；首页固定为 ，改了导航站地址首页也不会跟着变。 想换回 Firefox 自带的，在地址栏输入 about:preferences#home，在「新窗口和标签页」里改。 主页按钮默认不在工具栏上，可以在工具栏上右键 →「定制工具栏」拖出来。

用法

  • 点工具栏图标或按 Alt+Shift+S：AI 预填名称、分类、描述，确认后保存
  • 网页或链接上点右键 →「一键收藏到皮皮2047」：直接保存，网页右上角显示进度和存进了哪个分类
