# iOS 快捷指令：从分享菜单收藏网址

有两种做法：

- **浮层版（推荐）**：用「显示网页」在当前网页上方弹出添加表单，保存后关掉浮层就回到原网页。要先生成一个个人令牌
- **Safari 版**：用「打开 URL」在 Safari 新标签里打开导航站，不需要令牌，但每次都会跳出一个新标签

## 浮层版

浮层（Safari View）和 Safari、主屏幕 PWA 的本地数据互相隔离，读不到登录状态，「显示网页」也带不了请求头。
所以快捷指令先用个人令牌调 `POST /api/share/draft`，换来一个带短时令牌的 `/add` 网址，再用浮层打开它。
短时令牌 30 分钟过期，只能用来添加网站，保存成功后立即作废。接口说明见 `REST_API.md`。

### 设置步骤

1. 在导航站登录，用户菜单 →「个人令牌」生成一个令牌（比如叫「快捷指令」），复制下来
2. 打开「快捷指令」App，新建快捷指令，命名为「收藏到皮皮2047」
3. 点底部的 ⓘ，打开「在共享表单中显示」，接收类型只勾「URL」和「Safari 浏览器网页」
4. 添加动作「文本」，内容粘贴刚才的个人令牌
5. 添加动作「获取 URL 内容」：
   - URL：`https://pipi2047.eu.org/api/share/draft`
   - 方法：POST
   - 头部：`Authorization` = `Bearer `（注意后面有个空格）+ 上一步的「文本」变量
   - 请求体：JSON，加一个文本字段 `url` = 「快捷指令输入」
6. 添加动作「获取词典值」，键填 `edit_url`
7. 添加动作「显示网页」，输入选上一步的「词典值」

### 使用

在 Safari 或其它 App 里点「分享」→「收藏到皮皮2047」，浮层里会显示填好的表单和当前账号，
改完点「保存」，看到「已保存」后点左上角关闭浮层。

### 注意

- 个人令牌只放在快捷指令的请求头里，不会出现在网址中；把快捷指令分享给别人前要先删掉令牌
- 令牌泄露或不用了，在「个人令牌」里吊销
- 已经收录过的网址只提示「已经收录」，不显示表单
- 提示「链接已过期」时重新运行快捷指令即可
- 提示「云端还没有收藏数据」说明这个账号还没同步过，先在浏览器里登录导航站同步一次
- 不带令牌打开 `/add?url=<网址>`（比如在 Safari 里直接打开）会转到下面的 `/?add=` 流程

## Safari 版

iOS 的网页和主屏幕 PWA 不能自动读剪贴板，也不能出现在系统分享菜单里。用快捷指令打开
`https://pipi2047.eu.org/?add=<网址>`，导航站会弹出「添加网站」，填好网址并自动填写。

### 设置步骤

1. 打开「快捷指令」App，新建快捷指令，命名为「收藏到皮皮2047」
2. 点底部的 ⓘ，打开「在共享表单中显示」，接收类型只勾「URL」和「Safari 浏览器网页」
3. 顶部「接收 URL 和 Safari 浏览器网页（来自共享表单）」下方，「如果没有输入」选「获取剪贴板」
   （这样从主屏幕直接点这个快捷指令时，会用剪贴板里的网址）
4. 添加动作「URL 编码」，对象选「快捷指令输入」
5. 添加动作「打开 URL」，内容填 `https://pipi2047.eu.org/?add=`，后面接上一步的变量「URL 编码后的文本」

### 使用

- 在 Safari 或其它 App 里点「分享」→「收藏到皮皮2047」
- 或者先复制网址，再点主屏幕上的这个快捷指令（第一次会问是否允许读取剪贴板）

### 注意

- 快捷指令只能在 Safari 里打开网址，打不开主屏幕上的 PWA。PWA 和 Safari 的本地数据是分开的，
  要在 Safari 里也登录，保存后靠云端同步到 PWA
- 已经收录过的网址只提示「已经收录过了」，不弹窗
- 网址参数读完立刻从地址栏去掉，刷新不会重复弹出
