# 多语言界面

## 背景与范围

项目使用原生 HTML 和 JavaScript。语言运行时和翻译表由网站与浏览器扩展共用，不引入前端框架或翻译服务。

支持简体中文 `zh-CN`、繁体中文 `zh-TW` 和英语 `en`，覆盖首页、记事本、公开记事、工具页、关于/隐私/条款页面，以及扩展的弹窗、设置、右键收藏提示。页面标题、输入提示、辅助阅读标签、动态弹窗和通知也参与翻译。

收藏标题、描述、用户分类、文件夹名、笔记正文和默认示例收藏属于数据，不随界面语言改写。系统「未分类」仅在显示时翻译，存储中的名称不变。AI 生成描述仍使用现有服务端逻辑，不因界面语言改变。

## 使用方式

- 首页页脚有语言选择；其它网站页面在页眉选择。
- 扩展设置页可以单独选择语言，无需填写地址或令牌。扩展偏好与网站偏好分别存储。
- 首次打开按浏览器语言选择：`zh-Hant`、台湾/香港/澳门中文归入繁体，其它中文归入简体，英语各地区归入英语。不支持的语言回退到简体中文。
- 手动选择保存为网站 `localStorage.language` 或扩展 `storage.local.language`，下次打开仍有效。删除该项可恢复跟随浏览器。
- 网站支持 `?lang=zh-CN`、`?lang=zh-TW`、`?lang=en`，优先于本机偏好，便于预览或分享。手动选择成功保存后移除该参数；存储被禁用时保留参数作为当前页面的兜底。
- 网站切换语言会重新加载当前页面，保留路径和 hash。记事本在切换前立即保存本地草稿并在重载后恢复；保存进行中或草稿无法保存时取消切换。扩展设置原地切换，保留尚未保存的地址和令牌。
- 日期、数字、记事相对时间随当前语言格式化。英语窄屏工具标签在栏内可横向滚动。

## 维护翻译

唯一源文件：

- `public/locales.js`：每行是 `[简体中文原文, 繁体中文, 英语]`。简体原文同时作为键，缺少翻译时保留原文。
- `public/i18n.js`：语言选择、格式化、HTML 转义和静态页面翻译。

JavaScript 普通文本用 `I18n.t('保存')`。参数以完整句子组织，允许不同语言调整语序：

```js
element.textContent = I18n.t('已移到「{0}」', { 0: folder.name });
```

在 HTML 模板中用 `I18n.html()`，它会对译文和参数一起转义。传入原始文本，不要先调用 `escapeHtml()`，否则会重复转义：

```js
element.innerHTML = `<span>${I18n.html('文件夹「{0}」', { 0: folder.name })}</span>`;
```

静态 HTML 显式标记文案及属性：

```html
<span data-i18n="保存">保存</span>
<input placeholder="网站名称" data-i18n-placeholder="网站名称">
```

支持 `data-i18n` 和 `data-i18n-title/placeholder/aria-label/alt/content`。只给界面文案添加标记；不要给来自用户内容的节点添加。带子元素的容器应标记专门的文字 `span`，避免翻译时覆盖图标、表单或链接。静态标记在页面初始化时处理，动态界面用 `t/html` 在渲染时处理。

新增页面需在页头顺序加载 `/locales.js`、`/i18n.js`，并提供 `data-language-select` 选择器。新增脚本也需加入现有生产构建入口。改动简体原文时，同步更新所有语言和引用键，保留相同的 `{0}` 等占位符。

## 扩展与构建

扩展不能引用包外的文件。`extension/lib/i18n-bundle.js` 是上述两个源文件生成的包内副本，纳入版本控制，供 Chrome 直接加载；不要手动编辑。扩展模块通过 `extension/lib/i18n.js` 导入并等待偏好读取，后台和页面使用相同语言。

修改语言源文件后执行：

```bash
npm run build:extension  # 更新扩展副本
npm run check:i18n       # 检查固定键覆盖、页面入口和副本一致性
npm test -- --run        # 语言选择、参数转义、时间格式及原有功能测试
npm run build           # 网站生产构建
npm run build:firefox    # 同步翻译并生成 Firefox 扩展
git diff --check
```

网站构建包含语言脚本；Firefox 构建自动同步副本。没有新增运行时依赖。合并 `master` 的工具链升级后，测试配置位于 `vitest.config.mjs`，使用 Vitest 4 和 `@cloudflare/vitest-plugin`，关闭远程绑定，并保留 `test/**/*.spec.js` 的收集范围，避免把本机 `.claude/worktrees/` 中的旧测试一起运行。

## 验证与注意事项

浏览器中逐项检查三种语言、刷新和跨页面导航、搜索与网站编辑弹窗、工具功能，以及 320px 窄屏布局。记事本还应验证未保存草稿切换后的恢复。扩展需要重载后检查弹窗和右键菜单。

翻译在客户端生效，静态 HTML 和默认 PWA 安装清单仍以简体中文提供；搜索引擎与分享平台不执行页面脚本时会读取默认文案。现有默认示例收藏和 AI 生成内容也不会自动翻译。扩展的浏览器名称、安装介绍和快捷键说明通过 `_locales` 跟随浏览器语言，扩展设置中的选择控制运行时界面。
